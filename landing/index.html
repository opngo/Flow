03 / Detail

Three decisions that shape the whole app

Not features. Constraints: the things that had to be true before any screen was worth building.

Your database is a file you can open

A versioned JSON document with a schema, migrations and per-collection recovery: if one array is corrupt it is reset on its own instead of taking the file down with it. Saves are debounced, and the desktop build keeps rolling backups next to the file. 

// a focus block, as stored
{
  "phase": "focus",
  "startedAt": "2026-10-24T18:12:04.221Z",
  "endsAt":    "2026-10-24T18:37:04.221Z",
  "remainingMs": 1498000,
  "sessionsDone": 1
}

Timers are timestamps, not countdowns

Every running timer derives what is left from the wall clock, so a suspended process, a sleeping laptop or a reloaded window cannot make it drift. A safety tick runs every thirty seconds and the desktop build reschedules reminders when the machine wakes up. 

remaining = endsAt − now()          // never a counter
on resume:  recheck, then reschedule   // powerMonitor
on reload:  read endsAt, keep running  // no state loss

Nothing leaves the machine

No analytics, no crash reporting, no update ping, no account. The app requests nothing over the network, which also means it works the same on a plane, on a locked-down school laptop and on a machine that has not been updated since you installed it. 

requests:   0 per session
accounts:   none
sync:       none — export the file if you want it elsewhere

05

What it is, and what it is not

It is

  • +A single-user desktop app for one person's day, built to be opened first and closed last.
  • +Offline by construction. The only network code in the app is the download you used to install it.
  • +Backed by a file you own, with plain JSON export and import.
  • +Fast on old hardware. No web fonts, no remote assets, no background sync.

It is not

  • −A team product. No sharing, no comments, no permissions, no seats.
  • −Sync. One file, one machine. Move it with your own tools.
  • −An AI product. Nothing is generated, summarised or predicted for you.
  • −A mobile app. Desktop only, and the window is not responsive below a tablet.
A note on this page

Nothing on this page was generated for it

Marketing pages for software usually arrive with a stock photograph of a desk, a hosted webfont, an illustration set and a script that watches what you do with them. This one has none of that, because the product it describes has none of that either.

  1. Every illustration is drawn in code. The hero scene, the six interface panels and the logo are canvas draws and divs in this file.
  2. The photograph pretends to be a photograph. It is a five-tone dithered render of a desk, generated pixel by pixel; the counter under it is honest about the tone count.
  3. System type only. No webfonts are loaded, which is why the page looks slightly different on every machine and loads in one request.
  4. Copy written by a person. No listicle headers, no "unlock your potential", no invented statistics and no testimonials from companies that do not exist.
  5. No analytics. The page ships no scripts other than its own, sets no cookies and stores nothing about your visit.
