Flow

A local-first workbench for one person.

Scroll

Twelve tools, one file, no network.

Flow is a desktop workbench for one person: tasks, habits, goals, a focus timer, grades, notes, flashcards, a calendar, a sound studio and a hundred small tools. Everything goes into one JSON file in your user directory. There is no account screen because there are no accounts.

Free, MIT licensed, v1.2.0. Read the source or grab the installer for macOS.

It is not

  • A team product. No sharing or seats.
  • Sync. One file, one machine.
  • An AI product. Nothing is generated for you.
  • Telemetry. Zero requests per session.

Install

Builds are unsigned. On macOS right-click and Open; on Windows choose More info, then Run anyway.

git clone https://github.com/opngo/flow && cd flow && npm ci && npm run dev
