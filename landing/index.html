What is inside

Nine apps' worth of surface, one place to look.

Flow replaces the to-do app, the habit tracker, the pomodoro timer, the grade spreadsheet, the notes app and the ambient noise tab. Everything shares one schema, so a task can feed a habit, a timer can log study time, and a subject can own both.

Todos with eleven views

List, board, calendar, timeline, day planner, Eisenhower matrix, deadline radar, focus list, overdue rescue, completed log and projects. Drag to reorder, bulk-select, undo anything.

Habits that keep score

Daily, weekday, times-per-week, alternate-day or full recurrence rules. Streaks, longest runs, consistency, a weekly grid and auto check-in when a linked timer finishes.

Focus engine and timers

Pomodoro profiles with strict mode, breaks, extensions and distraction counting. Plus countdown, stopwatch, interval, routines, tracker and timesheet. Timers are clock-derived, so they survive sleep and restarts.

Analytics you can read

A 53-by-7 heatmap with filters and a day panel, plus subject, habit, hour and task breakdowns, streak statistics, custom intensity thresholds and SVG or PNG export.

Grades with real maths

Subjects own weighted categories with drop-lowest and best-N rules. Enter assignments, quizzes, tests and exams, then ask what you need on the final — for one subject or the whole term.

Markdown editor with live preview, folders, tags, double-bracket links and backlinks, a journal mode with mood tracking, zen mode, and word and reading-time statistics.

Install

Three platforms, one database format.

Download the installer for your system, or build it yourself from source. The database is a single JSON file you can copy, back up or version.

Windows

10 · 11 · ARM64

Per-user install, no administrator rights. Creates a Start Menu shortcut so notifications work.

Installer (.exe) Portable
winget install opngo.flow

macOS

Apple silicon · Intel

Drag Flow into Applications. Unsigned builds need a right-click then Open the first time.

Apple silicon Intel
brew install --cask opngo/tap/flow

Linux

AppImage · deb · tar.gz

Run the AppImage directly, or install the deb package if you use Debian, Ubuntu or a derivative.

AppImage .deb
chmod +x Flow-1.0.0-linux-x86_64.AppImage

Downloads resolve to the latest published release. Verify any file against SHA256SUMS.txt. All builds in a release are unsigned unless stated otherwise, so Windows SmartScreen and macOS Gatekeeper will ask once on first launch.

Build from source

Node 20 or newer. The packaged app and the browser build share one renderer.

git clone https://github.com/opngo/flow.git && cd flow
npm ci
npm run dev

Questions

The things people ask first.

One JSON database inside the app's user-data folder, plus rolling backups. Settings, Todos, Grades and the rest all read and write that single file.

Export it any time from Settings, Data, or press Ctrl K and run "Export everything". Import the file back on another machine and you are exactly where you left off.

No. No accounts, no analytics, no crash reporting, no update pings. The only network requests in the entire app are the ones you trigger by opening an external link yourself.

You can verify that in the source, and this page follows the same rule: it is one HTML file with no external fonts, scripts or images.

Code-signing certificates cost money and Flow is a free project. Windows SmartScreen shows "Windows protected your PC" once: choose "More info" then "Run anyway". On macOS, right-click the app and choose Open.

If you would rather not trust a binary, build it yourself in about two minutes — the source is right there.

Yes. Closing to the tray keeps timers and reminders alive. Every timer stores its start and end times and the remaining time is recomputed from the clock, so sleep, restarts and throttling cannot make it drift.

Reminders are held in the main process and catch up after a restart — a notification you missed arrives marked as missed rather than vanishing.

Electron with React, TypeScript, Headless UI, Tailwind and Zod. That means the same renderer runs in a browser tab, so you can try the whole application at npm run dev before installing anything.
